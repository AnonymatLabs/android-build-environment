## 📱 About The Project

**Android Build Environment v2 PRO** is an automated setup tool that creates a complete Android development environment inside **Termux**.

It installs and configures everything required to build modern Android applications without needing a computer.

The project provides:

- Android SDK
- Android Command Line Tools
- Android Platform Tools
- Android Build Tools
- OpenJDK 21
- Gradle
- Environment configuration
- Build verification system

Developed and maintained by:

**Anonymat Labs**
